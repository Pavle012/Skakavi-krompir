## Dependencies

Just need an internet connection on first run if `pygame`, `pillow` and `customtkinter` aren't already installed.  
If `pygame`, `pillow` and `customtkinter` aren't already installed, the script will automatically install them—either in the virtual environment or globally.

## Download

To download the latest stable version, go to the [Releases](https://github.com/Pavle012/Skakavi-krompir/releases) page and download the latest release.

Want to download the latest alpha version? You can download the binary at: [Nightly.link](https://nightly.link/Pavle012/Skakavi-krompir/workflows/buildalpha/main?preview) or you can clone/[download](https://github.com/Pavle012/Skakavi-krompir/archive/refs/heads/main.zip) this repository and use Python to run original/main.py or for the kivy version kivy_game/main.py (original reccomended for most use cases).
